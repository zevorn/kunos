# Security Policy

## Supported Branches

The `main` branch is the active development branch. Security fixes should be
based on `main` unless a stable branch is explicitly listed in this file.

## Reporting a Vulnerability

Report security issues privately by email to:

Chao Liu <chao.liu.zevorn@gmail.com>

Please include the affected recipe, layer revision, build configuration, and a
minimal reproducer when possible. Public issues are fine for ordinary bugs, but
do not publish exploit details before a fix is available.
